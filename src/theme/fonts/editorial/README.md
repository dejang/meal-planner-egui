# Recipe page typography

These unmodified fonts are bundled so the recipe editor works offline on both native and web builds.

- DM Serif Display Regular: https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
- DM Serif Text Regular and Italic: https://github.com/google/fonts/tree/main/ofl/dmseriftext

Both families are licensed under the SIL Open Font License 1.1. Their copyright notices and full license texts are included alongside the font files.
